# Git Test with Agent AI

This repository is a testbed for learning and practicing Git operations when pair-programming with an agentic AI coding assistant.

## First Time Working with Agent AI

Working with an Agent AI (like Antigravity) is an interactive, collaborative experience:
- **Natural Language Requests**: The developer provides intent in English, and the AI translates it to code changes, scripts, or git commands.
- **Auto-execution & Safety**: The AI executes command-line operations, file updates, and checks in a sandboxed terminal workspace.
- **Verification**: The AI can write test files, execute validation scripts, and report success or failure automatically.

## Repository Contents

* `auth.py`: Simple authentication module containing:
  * `login()`: Basic login stub.
  * `login_with_google(token)`: Simulated authentication logic using a Google OAuth2 token.
